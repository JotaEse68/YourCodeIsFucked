## استخدم ما تريد.

Claude Code · Codex · Cursor · Copilot · Gemini · Lovable · Bolt · يداك أنت

```text
               ابنِ بسرعة
                    ↓
          YCF — طبقة الجودة
                    ↓
             أطلق كوداً نظيفاً
```

**نحن لا نكتشف كود الذكاء الاصطناعي. نحن نكتشف الكود السيئ.**

YCF أداة CLI مجانية ومفتوحة المصدر لفهم قاعدة الكود، العثور على مشاكل هندسية قابلة للقياس، تنظيف البقايا المؤكدة بأمان، تخطيط التحسينات والتحقق من أن شيئاً لم ينكسر. إنها مناسبة لمبرمج الـ vibe، وللمطور الذي يستخدم الذكاء الاصطناعي، وللفريق الذي يحتاج بوابات جودة قبل الإطلاق.

البرمجة بأسلوب vibe ممتعة. التنظيف بعدها ليس كذلك.

## ابدأ هنا

```bash
npm install -g @jotaese68/ycf-cli
cd my-project
ycf audit
ycf map
ycf unfuck --dry-run
```

استخدم `--yes` فقط بعد مراجعة الخطة. ينشئ YCF نقطة تحقق Git، ويتحقق من النتيجة ويعيد التراجع إذا فشل التحقق.

## ما الذي يفعله YCF اليوم

- `ycf audit`: يدقق دون تعديل الكود ويشرح المخاطر بلغتك ومستوى التفاصيل الذي تختاره.
- `ycf map`: ينشئ خريطة معمارية لنقاط الدخول ووصلات الوحدات المحلية.
- `ycf ai-residue`: يبحث عن بقايا التطوير والذكاء الاصطناعي دون حذف الإسناد.
- `ycf cleanup --yes`: يحذف بقايا التصحيح المؤكدة وبعض الاستيرادات غير المستخدمة مع أمان Git.
- `ycf unfuck --dry-run`: يعرض المسار الآمن: تدقيق، نقطة تحقق، تنظيف، تحقق وتقرير.
- `ycf refactor`: ينشئ خطة خاضعة للإشراف بدلاً من إعادة كتابة البنية بصمت.
- `ycf verify` و`ycf release`: يشغلان الفحوصات وينتجان تقرير الجاهزية.

يدعم YCF تشخيصات حتمية لـ JavaScript وTypeScript وReact وPHP وWordPress. لا يعامل hooks أو filters أو shortcodes أو REST أو AJAX أو cron أو WooCommerce ككود ميت لمجرد عدم وجود استدعاء مباشر.

## شياطين قاعدة الكود

`DeadCode` و`CopyPaste` و`GodComponent` و`MysteryHelper` و`FinalFinalV3` و`TODOFromHell` و`DependencyNobodyUses`: أسماء مرحة لمشكلات تحتاج أدلة حقيقية. يوضح كل اكتشاف الملف والخطر والإجراء الآمن والقرار البشري المتبقي.

> «إنه يعمل» ليست وثائق. الإنتاج ليس إطار اختبار.

## هندسة جادة تحت المزحة

- `ycf audit` لا يعدل المصدر أبداً.
- التنظيف الآمن يتطلب worktree Git نظيفاً ونقطة تحقق و`--yes` صريحاً.
- المصادقة والمدفوعات وواجهات API العامة ومخططات قواعد البيانات والاستدعاءات الديناميكية لا تتغير تلقائياً.
- التراخيص وحقوق النشر والإسناد الإلزامي محمية.

## لماذا بنيت هذا

استخدمت الذكاء الاصطناعي لأبني أسرع. ونجح الأمر. لفترة.

ثم فتحت مشاريع مليئة بـ helpers مكررة، وpatches «مؤقتة» عمرها أشهر، ومجلدات `final-final-v3` ومكونات ضخمة لدرجة أنها بدأت تطلب عقد عمل جماعي.

كل شيء كان يعمل. تقريباً. لكن شرحه لشخص آخر أو مراجعته دون تعرق أو تسليمه كعمل احترافي كان قصة أخرى.

الجزء المزعج؟ كانت الفوضى فوضاي.

أردت الاحتفاظ بالسرعة من دون تنظيف مسرح الجريمة سراً. لذلك بنيت YCF: ليس لادعاء أن إنساناً كتب الكود، بل ليكون واضحاً وقابلاً للصيانة والتحقق وجاهزاً للإطلاق.

## CLI أولاً. ثم Skills والوكلاء.

جوهر YCF حتمي: يرسم ويقيس ويحمي بـ Git ويكتب تقارير ويتحقق. صمم للعمل مع Codex وClaude Code ووكلاء آخرين. Skills وتحليل الأثر الأعمق ولوحة محلية مرئية على خارطة الطريق وليست وظائف مكتملة بعد.

`ycf init` يختار اللغة ومستوى الشرح. الإنجليزية افتراضية، وتتوفر الإسبانية والبرتغالية والفرنسية والألمانية والإيطالية والعربية والصينية.

```bash
ycf audit --language ar --audience guided
ycf audit --audience professional
```
