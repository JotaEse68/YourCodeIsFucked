# Security policy

## Supported versions

Until YCF has a public stable release, only the latest commit on `main` is supported.

## Reporting a vulnerability

Please do not publish sensitive details in a GitHub issue. Contact the repository owner privately through the contact method shown on the GitHub profile, with:

- a clear description of the impact;
- minimal reproduction steps;
- affected files or commands; and
- a safe way to contact you for follow-up.

Do not include passwords, tokens, private keys, customer data, or production configuration in the report.

## Scope

YCF is designed to inspect code and explain risk. It must not expose scanned secret contents, publish user data, or automatically make sensitive application changes. Please report any behavior that could violate these boundaries.
